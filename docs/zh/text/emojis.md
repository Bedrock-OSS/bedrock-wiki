Minecraft 有大量硬编码的[私人用 Unicode 符号](https://en.wikipedia.org/wiki/Private_Use_Areas)，会自动转换为类似表情的符号。
这些可以在任何普通字母可以使用的地方使用，例如标牌、书籍、物品名称、聊天等。

下方你可以找到特定平台的表情以及通用符号。
你可以在[这里](/text/custom-emojis)学习如何创建自己的表情！

## 使用表情

在很多地方，Minecraft 允许你输入表情简码而不是实际字符。
但并非所有地方都支持这种方式，所以你可能需要直接复制粘贴"字符"列下方的字符到 Minecraft 中。
