Minecraft 服务器允许玩家通过互联网或局域网与其他人一起游戏。
[您可以在此处下载官方的 Mojang BDS 软件](https://www.minecraft.net/en-us/download/server/bedrock)。

除了原版 BDS 之外，还存在许多社区项目，使用多种不同的语言开发。
这些其他项目分为自定义服务器软件（Custom）和基于 BDS 的服务器软件（BDS-Based）。

服务器软件类型：

-   自定义服务器软件 = 完全从零开始开发的服务器软件。
-   基于 BDS = 在 BDS 基础上构建并进行修改的服务器软件。

您可能会注意到自定义服务器软件比基于 BDS 的解决方案更为普遍。这种差异可归因于以下几个因素，其中最值得注意的是：

-   长期缺乏官方服务器软件，BDS 于 2018 年 8 月 28 日首次发布，距 Bedrock 版于 2011 年首次发布约晚了七年。
-   在 1.21.10 版本中移除了符号（也称为 Mappings），这一改动最初是为了减少信息量，导致许多基于 BDS 的软件解决方案逐渐衰落。
