本指南将介绍为Minecraft Bedrock版建模时的技巧、窍门和注意事项。

## 纹理错位

有时某些（较小的）面上的纹理会出现错位或不可见的情况。这是因为立方体的大小在UV贴图计算中被向下取整。这意味着任何小于1的大小都会导致0像素宽的UV贴图，从而出现错位。为防止此问题，请确保你的所有立方体在每个方向上至少为1个单位。要创建更小的立方体，请使用膨胀滑块。
另一个解决方法是如果你必须使用较小的纹理，可以在每个方向上**将元素大小增加1**，然后**将元素膨胀-1**，但请注意这会导致较小的像素纹理不正确从而产生混合像素。

## 顶点吸附

顶点吸附是Blockbench中任何建模者都应该使用的便捷工具。它在处理圆形事物（如轮子）时非常有用。
你可以在移动和缩放工具的右上角找到此工具。它有两种模式：移动和缩放。以下gif展示了它的工作原理。

## 透明度

如果你使用半透明纹理（如彩色玻璃），你需要将该纹理的元素移动到元素列表的底部。否则，这些半透明元素背后的元素将不会在游戏中渲染。

## 纹理绘制

在学习纹理绘制时，最好的方法是参考他人的作品来练习绘制类似对象和表面的纹理。木材和金属的纹理模式是不同的，你应该考虑到这一点。好的指南包括
[Masteriano的纹理绘制技巧](https://www.blockbench.net/wiki/guides/minecraft-style-guide)
以及一般的像素艺术教程。

## 材质

你的模型中的透明或发光纹理是否能在游戏中工作，取决于应用给它们的材质。

| 材质 | 描述 |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| entity | 基本不透明材质 |
| entity_alphatest | 支持透明像素 |
| entity_alphablend | 支持半透明像素 |
| entity_emissive | 实体，alpha通道用作发光通道 |
| entity_emissive_alpha | alpha通道用于发光纹理，完全黑色+透明像素会透明渲染 |

## Z-fighting

当两个元素的面在同一位置时，就会发生Z-fighting，你可以同时看到它们的一半，如下图所示。
![](z-fighting.png)
你可以通过将其中一个膨胀 `0.01` 或 `-0.01` 来解决此问题，取决于哪个应该优先。

## 动画基础

在Blockbench中制作动画时，你可以手动设置每个关键帧，也可以使用变量和函数。
这里你将学习基础内容。
让我们从这张图片开始。

![](animations-1.png)

名称或 `animation.cuack` 是必不可少的。你不能在其中使用符号或大写字母，并且必须以 `animation.` 开头才能使动画正常工作。现在我们将使用的函数是

`Base + Math.sin((q.life_time + Offset) * Speed) _ pitch`

- Base 是骨骼的起始旋转/位置
- Sin 是我们都熟悉的数学函数
- `q.life_time` 是一个变量。是一个随着动画继续而不断增加的数字
- Offset 是我们用来使动画比其“原始”位置更早或更晚开始的数字
- Speed 是从顶部到底部所需的时间
- Pitch 是离原点的距离

![](animations-2.gif)

使用的函数：

`Math.sin((q.life_time+0.5)*150)*15`

一个用于位置，另一个用于旋转。

<MolangGraph code="Math.sin((q.life_time+0.5)*150)*15" :toY="2" :stepSize="0.001"/>

不要忘记，要使动画成为完美的循环，你需要关联sin方程的`speed`和动画的`time`。
下面是一个可以获得完美循环的数值表，但你还可以发现更多。

| Speed | Time | Group |
| ----- | ---- | ----- |
| 150   | 2.4  | 1     |
| 100   | 3.6  | 2     |

这些数字可以相乘但不能除，所以以下也有效
但只能是相同选项的倍数

| Speed | Time | Group |
| ----- | ---- | ----- |
| 150   | 4.8  | 1     |
| 200   | 3.6  | 2     |
| 300   | 2.4  | 1     |
| 300   | 3.6  | 1 & 2 |

现在并不是所有这些都能“循环”在一起。这就是Group列的作用。具有相同数字的可以一起工作。否则，循环中会出现可见的“错位”。

:::tip
你可以通过点击以下设置来使动画循环：
![](setting-loop.png)
:::

通过这个函数和创意，动物和恐龙可以被制作成行走、奔跑和攻击的动画。
你可以在[这里](https://bedrock.dev/docs/stable/Molang)了解更多关于查询和函数的信息。

## 动画速度

要轻松更改动画的速度，你只需在动画中乘以 `anim_time_update` 的默认值（默认为 `q.delta_time + q.anim_time`）：

<CodeHeader>RP/animations/my_entity.a.json#animations</CodeHeader>

```json
"animation.my_entity.my_animation": {
    "anim_time_update":"2 * q.delta_time + q.anim_time"
    //你的动画放在这里！
}
```

这将使动画运行速度加快2倍。我们可以将值调整到任何浮点数，甚至可以减慢动画速度。例如，使用0.5，动画将运行速度减慢2倍，等等。
