JavaScript 是互联网上众所周知的脚本语言。学习 JavaScript 将帮助你构建和开发使用脚本 API 的附加包。

建议你学习在线提供的免费 JavaScript 课程，例如：

-   [MDN JavaScript：JavaScript 语言概述](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Language_Overview)
-   [Codecademy：JavaScript 入门](https://www.codecademy.com/learn/introduction-to-javascript)
-   [freeCodeCamp.org：JavaScript 算法和数据结构](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures/)

## 脚本 API 资源

网上有相当多的与脚本 API 相关的资源。重要链接有 ⭐。

-   ⭐ [Microsoft 的示例 GameTests](https://github.com/microsoft/minecraft-gametests) - Minecraft Bedrock 版的行为文件示例 GameTest。Minecraft 支持 GameTests——JavaScript + MCStructures 的组合——用于验证 Minecraft 行为的各个方面。

-   ⭐ [官方脚本 API 文档](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/) - Microsoft 对实验性脚本 API 的高级介绍官方文档

-   [脚本 API 示例](https://github.com/JaylyDev/ScriptAPI) - 仅使用脚本 API 模块的 JavaScript 代码片段

-   [脚本 API 启动项目](https://github.com/JaylyDev/scriptapi-starter) - 专门为脚本 API 设置的 Visual Studio Code 工作区。此项目用于编写 JavaScript 代码（适用于 [TypeScript 用户](/scripting/typescript#script-api)）。
