_Minecraft_ 存在多种文件类型，均用于导入内容。所有 _Minecraft_ 文件都是重命名为使用 `mc…` 扩展名的 ZIP 档案。这些档案目前可分为三组：

-   **关卡（`mcworld` 和 `mcproject`）**：世界和项目的关卡数据及相关资源
-   **资源（`mcpack` 和 `mctemplate`）**：世界的装饰品或支持资源
-   **组合包（`mcaddon` 和 `mceditoraddon)`**：用于导入最多一个世界或项目以及任意数量的资源类型

Minecraft 的所有文件类型都可以作为任何文件打开，启动 Minecraft 并导入内容。导入包时，它们会自动解压缩为其组成的文件和目录。如果尚未打开，大多数文件类型将以普通模式启动 Minecraft；`mcproject` 和 `mceditoraddon` 将改为启动 Minecraft 进入编辑器模式。

## 关卡

关卡代表常规世界和编辑器项目的保存数据和相关资源。无论模式如何，所有关卡都会导入到 `com.mojang` 目录中的 `minecraftWorlds`。

导入现有保存关卡的完全重复将创建重复的保存关卡。如果包含多个关卡，组合档案只会导入一个关卡，包括嵌套的组合档案。

### 世界

`mcworld`
封装单个世界的档案

可以通过几种不同的方式创建世界档案：

-   压缩世界目录的_内容_，并将扩展名从 `zip` 重命名为 `mcworld`
-   使用世界游戏设置屏幕上的"导出世界"按钮
-   在编辑器模式下，从文件 → 导出为 → 可玩世界菜单选项导出世界。世界将保存到 `com.mojang` 文件夹中的 `projectbackups` 目录。
-   在编辑器模式下，运行 `/project export world` 命令。世界将保存到 `com.mojang` 文件夹中的 `projectbackups` 目录。

在编辑器模式下导入世界包会将世界作为项目导入。导入的世界将无法在编辑器模式之外访问，需要重新导出为世界才能游玩。世界档案中捆绑的编辑器扩展包将在编辑器模式外导入时保留。

### 项目

`mcproject`
封装单个编辑器项目的档案

可以通过两种不同的方式创建项目档案：

-   压缩项目目录的_内容_，并将扩展名从 `zip` 重命名为 `mcproject`。
-   使用世界游戏设置屏幕上的"导出项目"按钮
-   在编辑器模式下，运行 `/project export project` 命令。世界将保存到 `com.mojang` 文件夹中的 `projectbackups` 目录。

如果 Minecraft 未打开，启动 `mcproject` 文件将打开编辑器模式。如果 Minecraft 已打开但不在编辑器模式下，导入 `mcproject` 将失败。

## 资源

资源档案代表多个非关卡内容的单一实例：

-   行为包
-   资源包
-   皮肤包
-   世界模板

所有资源档案都包含一个描述其内容的清单。如果资源档案的清单 UUID 和版本与同类型的现有资源档案完全匹配，则资源档案将无法导入。请注意，行为包和资源包共享相同的 UUID/版本空间。在世界、项目或模板内自包含的行为包和资源包不会作为重复项计入导入目的。

两种资源扩展名 `mcpack` 和 `mctemplate` 在功能上看起来相同。最佳实践是对于行为包、资源包和皮肤包使用 `mctemplate`，对于世界模板使用 `mctemplate`，以便更清楚地了解正在安装的内容。任意数量的资源档案可以包含在组合档案中。

### 包

`mcpack`
代表单个行为包、资源包、皮肤包或世界模板的包。建议仅对世界模板使用 `mctemplate`。

包只能手动创建，方法是压缩行为包、资源包或皮肤包目录的内容，并将扩展名从 `zip` 重命名为 `mcpack`。行为包和资源包全局安装，不会与安装在世界、项目或模板中的匹配行为包或资源包冲突。

#### 行为包

行为包附加到服务器以更改或扩展游戏玩法。行为包安装到 `com.mojang` 文件夹中的 `behavior_packs` 目录。

开发行为包必须手动放置在 `com.mojang` 下的 `development_behavior_packs` 目录中。

#### 资源包

资源包附加到客户端以影响声音、视觉等。资源包安装到 `com.mojang` 文件夹中的 `resource_packs` 目录。

开发资源包必须手动放置在 `com.mojang` 下的 `development_resource_packs` 目录中。

#### 皮肤包

皮肤包是用于自定义皮肤的仅客户端包。皮肤包安装到 `com.mojang` 文件夹中的 `skin_packs` 目录。

开发皮肤包必须手动放置在 `com.mojang` 下的 `development_skin_packs` 目录中，但此功能似乎无法正常工作。

### 世界模板

`mctemplate`
代表单个行为包、资源包、皮肤包或世界模板的包。建议仅对世界模板使用 `mctemplate`。

世界模板安装到 `com.mojang` 下的 `world_templates` 目录。世界模板可以通过几种不同的方式构建：

-   压缩世界目录的_内容_，添加世界模板清单，然后将扩展名从 `zip` 重命名为 `mctemplate`
-   在编辑器模式下，使用世界游戏设置屏幕上的"导出模板"按钮
-   在编辑器模式下，运行 `/project export template` 命令。世界将保存到 `com.mojang` 文件夹中的 `projectbackups` 目录。

## 组合包

组合档案用于在单个导入操作中导入最多_一个_关卡档案和任意数量或组合的资源档案。通常，组合包的内容需要打包。目录也可以在组合档案的_顶层_给出，以导入资源类型（行为包、资源包、皮肤包和世界模板），而无需预先打包它们。组织用的嵌套子目录不能使用。

组合内容按通常处理。例如，在编辑器模式下导入包含 `mcworld` 的 `mcaddon` 将把世界作为项目导入。

组合档案也可以包含任意数量或嵌套的其他组合档案，甚至跨 _Minecraft_ 模式。嵌套组合档案不能用于绕过单一世界导入限制。

组合包只能通过压缩档案和资源类型手动构建。

### Add-Ons

`mcaddon`
通用组合内容档案

在编辑器模式下导入 `mcaddon` 包会将任何包含的世界作为项目导入。导入的世界将无法在编辑器模式之外访问，需要重新导出为世界才能游玩。资源类型照常导入。

### 编辑器 Add-Ons

`mceditoraddon`
编辑器模式的组合内容档案

如果 Minecraft 未打开，启动 `mcproject` 文件将打开编辑器模式。如果 Minecraft 已打开但不在编辑器模式下，导入 `mcproject` 将失败。
