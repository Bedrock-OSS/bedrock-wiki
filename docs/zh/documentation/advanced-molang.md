## 值

-   Molang 中的所有表达式都会返回一个值用于等式检查。大多数表达式返回 `0`。值得注意的是，赋值返回赋值的值，循环返回循环语句的解析值（如果存在的话）。
-   Molang 中的所有值实际上都是单精度浮点数。
-   `this` 用于引用字段在评估过程中累积的当前值。据观察，它只能用于动画，但在其他地方可能也可以使用。例如，如果累积的变换在骨骼的 `x` `scale` 上产生 `62`，则最终动画的 `x` `scale` 为 `-this` 将解析为 `-62`，取消之前的变换。这在原版动画中有多处使用。在动画上下文之外，`this` 似乎始终解析为 `0`。

### 布尔值

-   布尔值可在 Molang 中使用。`true` 解析为 `1`，`false` 解析为 `0`。

### 数字

-   您可以在数字前使用前导 `0`，例如，为了在代码中更好地对齐它们。
-   数字可以使用指数表示法，例如 `2.5e2`，等于 250。`e` 可以带 `+` 或 `-` 后缀来指定幂。
-   数字可以带单个 `f` 后缀，通常用于表示浮点值。这可以在原版代码中找到，但据信它没有任何功能。

### 字符串

-   字符串使用 `\`（在转义 JSON 中为 `\\`）作为某种转义或其他功能。尚不清楚这有什么功能。已知后续 2 个字符被传递到它们自己的子解析器，在关闭的 `'` 上不会正确退出；这意味着 Molang 字符串 `"v.type = '\\x';"` 是无效的。通常不允许 `'` 本身，因为它代表字符串的结束，但在 `\` 后的 2 个字符中允许使用。
-   字符串值（大部分）是增量式的，因为它们以浮点形式表示。可以使用等式或比较运算符比较 2 个单个字符字符串，甚至可以有效地"调整"单个字符字符串的内容此类多字符行为是未知的。

## 运算符

完整的优先级列表，从第一个到最后评估：

1. `()` 和 `[]`
2. `->`
3. `!` 和 `-`（一元否定）
4. `*` 和 `/`
5. `+` 和 `-`（二元减法）
6. `<`、`<=`、`>` 和 `>=`
7. `==` 和 `!=`
8. `&&`
9. `||`
10. `?` 和 `? :`
11. `??`
12. `=`
13. `return`

-   对于所有运算符，运算符从左到右考虑，但条件运算符除外。
-   同一语句中不能使用多个 `->`。
-   逻辑运算符会短路。

## 语句

-   赋值返回赋值的值。因此，如果您需要将单个值用于多个单独变量，可以链式赋值，例如 `v.iterator_x = (v.iterator_z = math.random_integer(16, 32));`。
-   花括号作用域内的最后一个语句不需要以 `;` 结束。
-   花括号作用域可以在任何可以使用表达式的地方使用。例如，`v.spawn_point ?? { v.target = false; };` 将在 `v.spawn_point` 未定义时将 `v.target` 设置为 `false`。

## 集合

-   数组下标的结果不能直接作为 `+`、`-`、`*` 或 `/` 的参数，但仍然可以直接用作函数参数（甚至是数学函数）或其他运算符。

## 评估

-   `initialize` 和 `pre_animation` 是延迟连接的。这些数组中的 Molang 字符串必须独立地语法有效，但所有独立字符串的基本连接也必须是有效的 Molang 输入。

## 限制

-    Molang 对任何语言功能都没有显示合理的限制，除了数字大小。据观察，循环计数、字符串长度、Molang 输入长度、集合大小等在非常不合理的情况下都能保持。
