## 延迟渲染管线开发了多长时间

-   **问**：延迟渲染管线开发了多长时间？制作这个管线有什么挑战？
-   **答**：延迟管线自 2020 年以来以各种形式开发。它部分是 RTX 管线优化的产物，部分是用于 Minecraft Legends 的管线。开发于 2022 年 3 月正式开始。

## 支持的平台

-   **问**：会有任何平台不被支持吗？
-   **答**：目前没有关于什么会或不会被支持的官方公告。如另一个帖子中提到的，我们的目标是在能够支持延迟的设备上尽可能广泛地可用，但确保视觉效果和性能在良好的游戏体验应有的位置。

-   **问**：我只在手机上玩 Minecraft，光线追踪、着色器等看起来太酷了！但我从未能够体验它们 😞 延迟照明会在 Android 设备上可用吗？
-   **答**：是的！延迟预览目前可在 Android 上使用，可作为 Beta 程序的一部分。也可在 Preview 中的 Xbox、iOS 和 PC 上使用！

-   **问**：延迟在 chromebook 上可用吗？
-   **答**：我们目前没有关于新平台何时可用的新闻可以分享，但我们肯定在测试并寻找可以处理延迟的额外平台。我们希望确保尽可能多的玩家能够体验新的图形模式，但也要确保游戏体验会很稳固。

## 独特的技术和功能

-   **问**：是否有任何图形技术是内部开发的，而不是依赖现有解决方案？例如，延迟大气似乎相当独特，是从零开始创建的还是已经存在的模型的实现？
-   **答**：我们采用的许多技术来自白皮书和在各种技术会议（如 Siggraph、GDC 等）上提交的演讲，所以我们做的东西在技术上并不是真正的新颖（对于游戏行业的图形开发来说通常是这样）。

    话虽如此，我们为许多技术添加了 Minecraft 特定的倾斜以确保与原版照明对等（例如，光以类似的方式衰减，对"方块感"的一些视觉强调，在原版照明中黑暗的场景在延迟照明中也很暗，等等）

    也有新方法的机会（如下界/末地维度的照明），但目前我们没有可以分享的额外信息。

## 是否有计划修复使用高度而非均匀性的体积雾使你失明？

-   **问**：添加更多背景。当您设置雾时，如果它使用高度参数而不是均匀的，它们的厚度在进入生物群系时达到最大值，然后随着您进一步深入逐渐消失到正确的高度。这是故意的还是 bug？

## 基于标识符的配置

-   **问**：更像是带有"是否有计划……"前缀的功能请求，但基于标识符的配置会相当有用。有时我想根据游戏玩法更改照明配置。需要某种命令或类似的东西来切换配置。也许只是脚本。

    特别是方向光，我想根据世界事件改变它。比如一个"世界毁灭者"boss 应该改变在主世界投掷光线的方式。作为这些基于标识符的文件的一个例子：

    ```json
    {
        "format_version": "1.20.80",

        "minecraft:directional_lights": {
            "description": { "identifier": "bao:world_destroyer_event" },

            "sun": {},
            "moon": {}
        }
    }
    ```

    然后类似的东西：

    ```swift
    /renderer lighting set bao:world_destroyer_event
    ```

    本质上，这使用了与雾相同的想法，即仅将它们映射到生物群系是不够的。它们需要在适当时应用的独立形式。

-   **答**：是的！这正是我们正在做的事情，并将在我们的照明和大气 JSON 中启用。标识方式将与 Fog 识别非常相似。创作者应该期望当此更改发布时，他们将不得不更新他们当前的 PBR 包以利用标识符，因为这将是一个破坏性模式更改。虽然它将非常简单，我们将提供如何执行它的指导。
