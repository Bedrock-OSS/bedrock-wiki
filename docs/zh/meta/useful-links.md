### 您的第一个附加包入门

-   [Bedrock 版附加包开发入门](https://learn.microsoft.com/en-us/minecraft/creator/documents/gettingstarted)：这些指南将向您展示如何从头开始构建您的第一个资源包和第一个行为包。
-   [Molang：初学者指南](https://learn.microsoft.com/en-us/minecraft/creator/documents/molangbeginnersguide)：Molang 是一种 Minecraft 编程语言，可用于编写一些高级附加包。
-   [GameTest 框架入门](https://learn.microsoft.com/en-us/minecraft/creator/documents/gametestgettingstarted)：这是测试游戏的最佳方式，它使用 JavaScript，这是世界上最流行的编程语言！
-   [使用 TypeScript 构建游戏体验](https://learn.microsoft.com/en-us/minecraft/creator/documents/scriptinggettingstarted)：TypeScript 是 Microsoft 的 JavaScript 副本。使用 TypeScript 编写附加包，您可以添加任何您能想到的功能！
-   [@minecraft/server 模块](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/mojang-minecraft/mojang-minecraft)：这个模块以及附近的其他模块是我们可以使用 TypeScript 代码访问 Minecraft 值的方式。它是技术性的，但很棒的资源。
-   [命令列表和摘要（非官方 Minecraft wiki）](https://minecraft.wiki/w/Commands#List_and_summary_of_commands)：大多数附加包都会运行一些命令。这个社区支持的 wiki 是学习每个命令的最佳资源。
