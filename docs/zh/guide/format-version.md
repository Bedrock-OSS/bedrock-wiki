格式版本是 Minecraft：基岩版 Add-On 系统的重要组成部分。它们出现在大多数文件的顶部，格式如下：`"format_version": "1.21.0"`。你可以把它看作文件的"版本号"，你选择的数字非常重要！你在这里选择的格式版本将决定在该特定文件中可以使用哪些语法和功能。

:::tip
选择错误的格式版本是错误的常见来源。在故障排除时，人们可能会问你类似"你的物品是什么格式版本"的问题。确保你知道如何回答这个问题。
:::

## 为什么存在格式版本？

格式版本的存在是为了对 Add-On 系统进行_版本控制_，并允许 Minecraft 在不破坏旧 Add-On 的情况下将新功能引入 Add-On 系统。例如，`1.8.0` 格式版本的 RP 实体文件的语法与 `1.10.0` 格式版本的 RP 实体文件非常不同。通过在 json 中使用 `format_version` 键，你可以决定使用哪个版本。

通过_每个文件_使用格式版本，Minecraft 让你能够很好地控制你的 Add-On 将如何被游戏解释。在你的 Add-On 中混合不同的格式版本是完全可以的，也是预期的。

## 格式版本不是游戏版本

理解格式版本是_每个子系统_的，并且通常不等于基础游戏版本非常重要。这仅仅意味着每种类型的文件（物品、RP 实体、BP 实体、配方）将使用不同的版本控制系统。

例如：RP 实体文件中的 `"format_version": "1.8.0"` 意味着"使用_物品系统_的版本 `1.8.0`"。它_不是_意味着"使用_Add-On 系统_的版本 `1.8.0`"。

因此，某些文件类型会有非常"旧"的格式版本。不要 tempted 用最新的游戏版本替换这个版本，例如 `1.17.0`。

## 格式版本修复

Minecraft 有一个系统，如果你写错了格式版本，它会"修复"你的格式版本。这个系统没有被很好地理解，并非在所有系统上都启用了，不应该依赖它。但重要的是要注意，错误的格式版本通常会"向下回归"，直到达到有效的格式版本。例如，`1.11.0` RP 实体文件将被解释为 `1.10.0`，不会导致任何错误。

这个系统很有用，因为它意味着你不太可能通过选择错误的格式版本而生成一个坏文件。

## 选择格式版本

一般来说，有一个技巧可以帮助你选择任何文件类型的正确格式版本。

例如，假设你正在创建一个配方文件：

1.  安装[原版包](/guide/download-packs)。
2.  查看一些配方文件，判断哪个格式版本使用最多或最新。
3.  在你的文件中使用这个格式版本。

这个简单的技巧将帮助你为文件选择有效的格式版本。
