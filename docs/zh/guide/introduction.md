## 什么是 Add-On？

Add-On 是 Minecraft: Bedrock Edition（_Android、Chromebook、主机、Windows、iOS_）中相当于 Java Edition 模组的功能。

不过与 Java Edition 不同的是，Bedrock Edition 的 API 由 Mojang 官方维护而非社区维护，并且具有向后兼容性。这意味着为旧版本 Minecraft 制作的 Add-On 在未来版本中仍然可以正常工作。

一般来说，你可以把_模组_理解为_修改_游戏，而把_Add-On_理解为在 Mojang 提供的开发框架下_扩展_游戏。虽然直接修改原版内容是支持的，但如果多个 Add-On 修改了相同的内容，可能会导致不兼容，因此不推荐这样做。

:::tip 其他资源
虽然我们对本指南感到满意，但它并不是入门的唯一选择。Mojang 在 Creator Platform 上维护了他们自己的[入门指南](https://learn.microsoft.com/minecraft/creator/documents/gettingstarted)，如果你需要其他解释，可以参考。
:::

## 我将学到什么？

本指南是一份新手教程，旨在引导你完成 Add-On 制作的初始阶段。你将创建一个功能完整的 Ghost 实体，以及一个 Ectoplasm 物品和一些其他相关文件。

完成本指南后，你将独立制作出一个完整的 Add-On，并且可以自由使用和修改它！

## 指南是否是最新的？

本指南基于 Minecraft: Bedrock Edition 最新的_稳定_版本编写。许多内容在旧版本中可能无法使用，而某些内容在后续版本中可能会发生变化。

我们会尽可能保持指南的更新，所以无需担心。
